# V1 Scope

## Shipping in 1.0
- Local audio import (any DRM-free audio file)
- Routine section markers with waveform trimmer
- Practice block builder
- Reps / rest / lead-in controls per block
- Live run mode with big coach-friendly controls
- Visual lead-in countdown
- Auto vs manual restart mode per block
- Saved local templates (App Support, JSON)
- Quick restart / skip / previous block controls
- Estimated total session time

## Cut from 1.0 — moved to 1.1
- Per-block metronome (audio click track — UI was placebo in 0.x; stripped 2026-05-19)
- Lead-in audio cue (beep per second + go-tone)
- Voice countdown

## Explicitly not in v1
- AI section detection
- Trigger-based listening restart
- Cloud sync
- Accounts / backend
- Analytics dashboards
- Collaboration / sharing
- iPad layout (iPhone-only at launch)
- Mac Catalyst (dev convenience only, not shipped)
