# V1 Scope

## Must have
- Local audio import
- Routine section markers
- Practice block builder
- Reps / rest / lead-in controls
- Live run mode with big coach-friendly controls
- Per-block metronome toggle
- Saved local templates

## Should have
- Voice/beep countdown cue
- Duplicate / reorder blocks
- Quick restart and skip controls
- Estimated total session time

## Explicitly not in v1
- AI section detection
- Trigger-based listening restart
- Cloud sync
- Accounts/backend
- Analytics dashboards
- Collaboration / sharing
