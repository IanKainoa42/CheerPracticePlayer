Common questions

How do I import an audio mix?

Open the Builder tab and tap the import button. The system Files picker will open — choose any DRM-free audio file (MP3, M4A, WAV, AAC). The file is copied into the app's container so it works offline.

Why are my saved templates gone?

Templates are stored in the app's container. They are removed when you uninstall the app. They are included in your device's iCloud/iTunes backups if you have those enabled.

Does the app work without internet?

Yes — entirely offline. The app does not communicate with any servers.

Where is the metronome?

Audio metronome is planned for version 1.1. Version 1.0 ships with the visual lead-in countdown only.

Will there be an iPad version?

iPad layout is planned for a future update. Version 1.0 is iPhone-only.
