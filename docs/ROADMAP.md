# Roadmap

## 1.0 — App Store launch (summer 2026)
- Real local audio import
- Persistent session templates
- Section markers + waveform trimmer
- Practice block builder (reps / rest / lead-in / restart mode)
- Live run mode with big coach controls
- Visual lead-in countdown
- iPhone-only, iOS 18

## 1.1 — Coach audio cues
- Audio metronome (per-block tempo, default 160 BPM)
- Lead-in beep per second + go-tone
- Voice countdown option ("5, 6, 7, 8")

## 1.2 — Tablet & polish
- iPad layout
- Bluetooth speaker reliability testing
- Estimated total session time on home screen
- Duplicate / reorder blocks UX

## Later
- Template sharing
- Apple Watch / remote controls
- Trigger-based manual restart options (clap, voice cue)
- Coach notes per section
- Mac Catalyst polish (if demand)
