## Description

PracticeMix turns your routine mix into a programmable practice tool. Mark the sections you want to drill — tumbling, choreo, full-out, an 8-count, a stand tune — set how many reps, how long to rest between, and the get-ready countdown handles itself. Then hit play and let the app run the practice while you coach.

Built for cheer routines, dance choreography, marching band field drill, gymnastics floor, skating programs — any practice that runs off a music mix.

PROGRAMMABLE PRACTICE
• Import any audio mix from your Files
• Trim section markers with a waveform editor
• Build practice blocks with reps and rest per section
• Save your full library of mixes for one-tap reuse

LIVE RUN MODE
• Large play / pause / skip / restart controls — designed for fast-moving practices
• Visual lead-in countdown before each rep
• Auto-restart or manual restart per block
• Jump to any block in the queue
• Estimated session time at a glance

BUILT FOR THE GYM FLOOR
• Big buttons, high-contrast UI — readable from across the mat
• One-tap skip, restart, and previous-block
• Section progress and total reps always visible

LOCAL ONLY
• Your mixes and templates stay on your device
• No accounts, no cloud, no analytics
• Works offline at any gym

Made by a coach for coaches. No fluff — just the controls you actually need to run a practice.
